# Agent Skills

Project-local skills capture repeatable workflows that Codex should follow. Each skill is a folder
with a `SKILL.md` whose frontmatter `name` matches the folder name (Agent Skills layout, see
https://agentskills.io). Codex, OpenCode, and other compatible tools discover `.agents/skills/`
automatically. Keep skills short, reviewable, and tied to real project checks.

Starters:

- `first-session/SKILL.md`: inspect before editing and propose one safe improvement.
- `knowledge-propose/SKILL.md`: draft reviewable knowledge proposals at the end of a session.
